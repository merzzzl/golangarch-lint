# GOLANGARCH

Architecture instruction for this repository, generated from `.golangarch.yml` by golangarch-lint.
Follow these rules when creating, moving or editing Go code. Run `golangarch-lint lint .` to verify.
Do not edit this file manually — regenerate it with `golangarch-lint docs`.

## Always enforced (no configuration)

- The package name must be exactly equal to its directory name (`package main` is exempt).
- Every directory containing `.go` files must be covered by at least one rule below.
- `*_test.go` files are always ignored by all checks.

## File binding

- Default mode is `file-binding: name`: exported functions/methods must match the filename; unexported names must start with it. Names are normalized by removing underscores and the .go suffix, then lowercasing.
- In `file-binding: type` mode, types must match the filename and methods must have a receiver of a matching type declared in that same file. Value, pointer and generic receivers are supported. Plain functions retain name binding.
- Declaration restrictions still apply independently. Excluded function/type names are exempt from their respective AST checks; excluding a type does not exempt its methods.

## Ignored paths (invisible to all checks)

- `**/*_test.go`
